Compression

Uses the original compression specimen schematic for the project compression test program. Reference compression modulus and strength are anchored to the measured dataset.

Flexural

Uses the original flexural specimen schematic for the project beam-test program. Final flexural model should be replaced by regression fitted to the completed beam-test dataset.

Important: density conversion is physics-based. Mechanical-property estimates away from the reference composition are provisional screening values until enough experimental compositions are available to fit and validate composition–property relationships.
